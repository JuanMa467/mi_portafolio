Juan Manuel Atencio — Portfolio
Bienvenido al repositorio de mi portfolio personal. Este espacio está diseñado bajo un enfoque minimalista, tipográfico y editorial, priorizando la claridad visual, la performance y una experiencia de usuario fluida para presentar mis proyectos y habilidades como desarrollador de software.

Desarrollado con Astro, Tailwind CSS y JavaScript, el sitio busca alejarse de las plantillas oscuras genéricas de desarrollo para adoptar una estética limpia y estructurada inspirada en el diseño editorial moderno.

🛠️ Tecnologías & Stack
El portfolio está construido utilizando herramientas que garantizan modularidad, velocidad de carga óptima y un código mantenible:

Frontend: Astro (Componentes e Islas), Tailwind CSS, JavaScript (ES6+).

Tipografías Core: Syne (Display) y Fraunces (Serif Italic) para lograr el contraste editorial.

Iconografía: Devicon (filtrado monocromático para consistencia visual).

📂 Proyectos Destacados
Dentro de mi ecosistema de desarrollo, actualmente me encuentro construyendo y manteniendo:

🚗 ParkScan
Sistema automatizado para la gestión y optimización de estacionamientos.

Stack: Python, Supabase (PostgreSQL), Vitest para testing unitario de operaciones CRUD.

Enfoque: Arquitectura estable, consistencia de datos y backend testeado a fondo para garantizar flujos correctos.

💆 ESPielCalma
Plataforma digital a medida orientada a la oferta y gestión de servicios estéticos profesionales.

Stack: React, Node.js, Tailwind CSS.

Enfoque: Diseño centrado en la conversión del cliente, maquetación limpia y navegación intuitiva para tratamientos especializados.


🎨 Decisiones de Diseño & Arquitectura
Identidad Visual Cohesiva: El proyecto centraliza su paleta cromática mediante variables CSS nativas (--paper, --ivory, --accent, --charcoal), forzando a que secciones típicamente aisladas (como la grilla de habilidades) hereden la estética general del Hero.

Enfoque en la Calidad del Código: Priorizo la transformación de ideas complejas en código estable, modularizado a través de componentes reutilizables de Astro.

🚀 Instalación y Desarrollo Local
Si querés clonar este proyecto y ejecutarlo en tu entorno local (asegurate de tener Node.js instalado):

Clonar el repositorio:

Bash
git clone https://github.com/JuanMa467/mi_portafolio.git
Instalar las dependencias:

Bash
npm install
Iniciar el servidor de desarrollo:

Bash
npm run dev
Construir para producción:

Bash
npm run build
